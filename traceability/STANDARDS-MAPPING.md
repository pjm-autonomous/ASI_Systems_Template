## How to Fill This In

1. For each standard, decide: does it apply to this project at all? Record the decision and who made it.
2. Record the intended posture — most ASI standards are used as **engineering reference** rather than a **certification target**; state explicitly which applies (see `reference/standards-framework.md`'s "ASI compliance posture" section).
3. Score current coverage using the scoring tables in `reference/standards-framework.md` where provided (IEC 60204-1, ISO 26262, ISO 9001 §8.3 all have explicit 0–5 scoring rubrics).
4. Record gaps and link to the extension folder or artifact that will close them.
