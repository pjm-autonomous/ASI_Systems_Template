# RACI Matrix for Deliverable

<!-- STUB -->

Structure from PDP-08 rev A §3. This matrix defines the ownership model for creation, support,
review, and approval of the PRD itself. Change it only when the specific product requires a
materially different contribution or decision model. Use **role titles, not named
individuals** — a name-keyed table is a drift source when personnel change; names live in
`meta.yaml`.

The Product Manager owns product intent and document completion; Systems Architecture /
Systems Engineering is a co-responsible drafting partner so the PRD is actionable for
downstream engineering use. Supportive and Consulted roles contribute input and review; the
Accountable role approves the document for progression and use.

| Role | Stakeholders |
|---|---|
| Responsible | [Product Manager, Systems Architect] |
| Accountable | [VP of Product Development] |
| Supportive | [Engineering] |
| Informed | [Leadership, Marketing, Program Management] |
| Consulted | [Business Development, Tech Group] |
