# Glossary

`GLOSSARY.md` holds shared terminology for this project — add a term the first time it's used in an artifact with any risk of ambiguity, rather than letting each author define it slightly differently across files.

Prefer citing an established definition (e.g. from `ISO/IEC/IEEE 24765`, the systems/software engineering vocabulary standard — see `reference/standards-framework.md`) over inventing project-specific phrasing for a concept that already has an industry-standard term. Reserve project-invented definitions for concepts that are genuinely specific to this project (a custom stop-mode name, an internal service name), and say so when you add them.
