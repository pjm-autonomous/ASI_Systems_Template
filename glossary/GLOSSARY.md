# Glossary

Shared terminology for this project. Add terms as they come up in artifacts rather than letting inconsistent language spread across documents.

| Term | Definition |
|---|---|
| Persona | A stakeholder who interacts with the system across its lifecycle |
| Use case | A specific need a persona has of the system |
| Product requirement | A stakeholder-facing statement of what the system shall do to satisfy a use case |
| System requirement | Engineering decomposition of a product requirement, allocated to a component/subsystem |
| ICD | Interface Control Document — a contract between components, subsystems, or external systems |
| ADR | Architecture Decision Record — why a significant design choice was made |
| Cat 0 / Cat 1 / Cat 2 | IEC 60204-1 stop categories — see `reference/standards-framework.md` |
