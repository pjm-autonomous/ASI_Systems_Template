# Security

This repository holds systems architecture / systems engineering artifacts. It should not contain secrets, credentials, customer data, or export-controlled technical data — treat any such material as an incident if found.

## Reporting a Concern

Do not open a public GitHub issue for a security concern. Instead, report it directly to the repository owner or ASI's internal security contact through the normal internal reporting channel.

## Scope Note

If this project produces or references safety-relevant or cybersecurity-relevant requirements (see `extensions/safety/` and the IEC 62443 section of `reference/standards-framework.md`), those are engineering artifacts, not vulnerability reports — file them as normal requirements/architecture artifacts, not through this process.
